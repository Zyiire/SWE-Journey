# swe-journey

> 119 days from beginner to full-stack. Sep 5, 2026 → Jan 1, 2027.

**This is a public learning log.** Every day between those dates has a concept, a build task,
and a commit. The repos this produces are listed at the bottom as they get built.

---

## The goal

By January 1 I want to be able to design, build, test, and deploy a full-stack web application
on my own backend, database, frontend, auth, and CI — and explain every decision in it.

## Rules I set for myself

1. Type every line. No copy-paste from tutorials or AI.
2. Twenty minutes of debugging on my own before I search or ask.
3. Every project gets deployed. A repo that isn't live doesn't count.
4. Commit every day — but only real work. No padding.
5. Half a day beats no day.
